# Decisiones terminológicas del capítulo del dolor

Complementa `GUIA_DE_TRADUCCION.md` y `TERMINOLOGIA_TACTO.md`. El título del
capítulo queda **De la lesión física al desamor: sentir el dolor**.

- *nociceptive pain* → **dolor nociceptivo**; *nociceptor* → **nociceptor**;
  *free nerve endings* → **terminaciones nerviosas libres**.
- *noxious* → **nocivo**; *mechano-nociceptors* → **nociceptores mecánicos**.
- *transduction* → **transducción**; *receptor potential* → **potencial de
  receptor**.
- *visceral pain* → **dolor visceral**; *somatic pain* → **dolor somático**;
  *referred pain* → **dolor referido**.
- *hyperalgesia* → **hiperalgesia**; *allodynia* → **alodinia**; *sickness
  behaviour* → **conducta de enfermedad**.
- *spinothalamic tract* → **tracto espinotalámico**; *lamina I/II* → **lámina
  I/II**; *transmission cells* → **células de transmisión**.
- *dorsal root ganglion* → **ganglio de la raíz dorsal**; *withdrawal reflex*
  → **reflejo de retirada**.
- *Gate Control Theory* → **teoría de la compuerta**.
- *periaqueductal grey (PAG)* → **sustancia gris periacueductal (SGPA)**; en
  la primera mención se conserva *PAG* en cursiva.
- *locus coeruleus* → **locus cerúleo**; *raphe nuclei* → **núcleos del
  rafe**; *medulla* → **bulbo raquídeo**.
- *anterior cingulate cortex (ACC)* → **corteza cingulada anterior (CCA)**;
  *insula* → **ínsula**; *secondary somatosensory cortex* → **corteza
  somatosensitiva secundaria**. Se conserva la sigla **VPL**.
- *neuropathic pain* → **dolor neuropático**; *thalamic syndrome* →
  **síndrome talámico**; *stroke* → **accidente cerebrovascular (ACV)**.
- *psychogenic pain* → **dolor psicógeno**; *social pain* → **dolor social**;
  *Social Pain Theory* → **teoría del dolor social**.
- *NSAIDS* → **antiinflamatorios no esteroideos (AINE)**; *ibuprofen* →
  **ibuprofeno**; *lidocaine* → **lidocaína**; *gabapentin* →
  **gabapentina**; *ketamine* → **ketamina**. Se conserva **TENS**.
- *phantom limb pain* → **dolor del miembro fantasma**; *mirror therapy* →
  **terapia del espejo**; *cordotomy* → **cordotomía**; *myelotomy* →
  **mielotomía**.
- *severe* → **intenso** o **grave**; *behaviour* → **conducta**.
- *heartache* → **desamor**, como en el título.
- *fMRI* → **resonancia magnética funcional (RMf)**.
- *paracetamol* se conserva; el título de DeWall et al. (2010) dice
  *acetaminophen* y permanece así en la bibliografía.

## Notas editoriales

El original no se corrige en silencio. Estas formas se regularizaron en la
traducción y quedan asentadas acá:

- «Brown-Séquard Syndome» (falta la r) → **síndrome de Brown-Séquard**.
- «rarety» → **rareza**.
- «first put proposed» → **se propuso por primera vez**.
- «nociceiptive» → **nociceptivo**.
- «osteroarthritis» → **osteoartritis**.
- «dishibition» → **desinhibición**.
- «Mechano-sensitive ions channels» → **canales iónicos mecanosensibles**.
- El cuerpo remite a «Figure 12» y, en el recuadro de la terapia del espejo,
  a «Figure 16». Las figuras del capítulo están numeradas 4.12 y 4.16.
- El epígrafe de la Figura 4.12 («sees the nociceptor axon synapses») se
  tradujo con el sentido del esquema: el axón hace sinapsis con la
  interneurona.
- «central laminar nuclei» / «central laminar nucleus» se tradujo de manera
  literal como **núcleos laminares centrales** y **núcleo laminar central**.
  El nombre anatómico habitual es núcleos intralaminares; no se sustituyó.
  El rótulo de la Figura 4.13 dice *ventral posterior lateral (VPL) thalamus*
  y quedó como **tálamo ventral posterolateral (VPL)**.
- El cuerpo cita «Hart, 1998»; la referencia es Hart, B. L. (1988). Se
  conservó el año de cada lugar.
- El cuerpo cita «De Wall et al., 2010»; la referencia es DeWall. En el texto
  se usó **DeWall**, para que coincida con la lista.
- El cuerpo cita «Kulkarn»; la referencia es Kulkarni. En el texto se usó
  **Kulkarni**.
- El cuerpo dice «transcutaneous magnetic stimulation (TMS), a technique
  similar to TENS». Se tradujo como **estimulación magnética transcutánea
  (TMS)** y se conservó la sigla. El nombre habitual de la TMS es
  estimulación magnética transcraneal (EMT).
- «therapies test» → **terapias evaluadas**. «receiving and injection» y
  «so if when» → **recibir una inyección** y la condicional correspondiente.
  «individual re-gaining» → **la persona recupera**. «the spinothalamic tract
  cross» → **cruza**. «powerful methods of pain control» y «serve to the
  protect» se tradujeron con la concordancia del sentido.
- La revista de Eisenberger et al. (2003) figura como *Advancement of
  Science*. Se conservó. El DOI corresponde a *Science*.
- El HTML parte varios nombres de revista. El texto visible de Hart queda
  «Neuroscience and Biobehavioral Review»; se conservó esa forma. Los
  espacios partidos dentro de *Pain Medicine*, *Frontiers in Psychology*,
  *eClinicalMedicine*, *BJA Education*, *Indian Journal of Palliative Care*
  y *Journal of Pain Research* se reunieron. Los DOI que el original parte
  con un espacio (DeWall, Macdonald y Leary) se escribieron sin ese espacio.
