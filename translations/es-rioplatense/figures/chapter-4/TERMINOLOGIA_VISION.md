# Decisiones terminológicas del capítulo de la visión

Complementa `GUIA_DE_TRADUCCION.md`. El título queda **Iluminar el mundo: el
sentido de la visión**, en paralelo con «Sentir el mundo: el sentido del
tacto».

- *light* → **luz**; *electromagnetic spectrum* → **espectro
  electromagnético**; *wavelength* → **longitud de onda**; *frequency* →
  **frecuencia**; *transverse wave* → **onda transversal**.
- *photoelectric effect* → **efecto fotoeléctrico**; *photon* → **fotón**;
  *gold-leaf electroscope* → **electroscopio de laminillas de oro**.
- *retina* → **retina**; *photoreceptor* → **fotorreceptor**; *rod* →
  **bastón**; *cone* → **cono**; *fovea* → **fóvea**.
- *scotopic / photopic* → **escotópica / fotópica**; *acuity* → **agudeza**;
  *receptive field* → **campo receptivo**; *spectral sensitivity* →
  **sensibilidad espectral**.
- *cornea* → **córnea**; *lens* del ojo → **cristalino**; *corrective lens* →
  **lente**; *glasses* → **anteojos**; *ciliary muscles* → **músculos
  ciliares**.
- *dioptric apparatus* → **aparato dióptrico**; *focal point* → **punto
  focal**; *refractive error* → **error de refracción**.
- *myopia / short-sightedness* → **miopía / vista corta**; *hyperopia /
  long-sightedness* → **hipermetropía / vista larga**; *presbyopia* →
  **presbicia**; *bifocal / varifocal* → **bifocal / progresiva**.
- *rhodopsin* → **rodopsina**; *iodopsin* → **yodopsina**; *opsin* →
  **opsina**; *phototransduction* → **fototransducción**; *transducin* →
  **transducina**; *phosphodiesterase* → **fosfodiesterasa**; *guanylyl
  cyclase* → **guanilil ciclasa**.
- *dark current* → **corriente de oscuridad**; *bipolar cell* → **célula
  bipolar**; se conservan **ON**, **OFF**, **AMPA** y **mGluR6**.
- *cGMP* → **monofosfato de guanosina cíclico (GMPc)**; *GDP* y *GTP* se
  conservan, con el nombre en español en la primera mención.
- *retinal ganglion cell* → **célula ganglionar de la retina**; *optic nerve*
  → **nervio óptico**; *blind spot* → **punto ciego**; *optic chiasm* →
  **quiasma óptico**; *optic radiation* → **radiación óptica**.
- *lateral geniculate nucleus (LGN)* → **núcleo geniculado lateral (NGL)**;
  en la primera mención se conserva *LGN*.
- *primary visual cortex / striate cortex* → **corteza visual primaria /
  corteza estriada**. Se conservan **V1** a **V8** y **MT**.
- *ocular dominance columns* → **columnas de dominancia ocular**;
  *hypercolumns* → **hipercolumnas**; *retinotopic* → **retinotópico**.
- *dorsal / ventral stream* → **vía dorsal / vía ventral**; *what / where
  pathway* → **vía del «qué» / vía del «dónde»**.
- *superior / inferior colliculus* → **colículo superior / colículo
  inferior**; *blindsight* → **visión ciega**.
- *trichromacy* → **tricromía**; *opponent processing* → **procesamiento
  oponente**; *colour constancy* → **constancia del color**.
- *interposition* → **interposición**; *linear perspective* → **perspectiva
  lineal**; *size constancy* → **constancia del tamaño**; *binocular
  disparity* → **disparidad binocular**.
- *cataract* → **catarata**; *glaucoma* → **glaucoma**; *age-related macular
  degeneration (AMD)* → **degeneración macular asociada a la edad (DMAE)**;
  *dry / wet* → **seca / húmeda**; *photodynamic therapy (PDT)* → **terapia
  fotodinámica (TFD)**.

## Notas editoriales

El original no se corrige en silencio. Estas formas se regularizaron en la
traducción y quedan asentadas acá:

- El cuerpo remite a «Figure 32» y a «Figure 41». Las figuras están numeradas
  4.32 y 4.41.
- El cuerpo cita la teoría del procesamiento oponente como «Figure 4.43». La
  figura que sigue es la 4.44; la 4.43 es la de las vías dorsal y ventral. La
  traducción remite a la Figura 4.44.
- «mostly likely», «sensitivies», «referred to rhodopsin» (sin *as*), «ions
  channels», «a structure call», «capable for detecting», «a series steps»,
  «likely be» y «answered ‘No’ this question» se tradujeron con la forma
  gramatical correspondiente.
- «oversight (no pun intended)» se tradujo como **visión de conjunto**. El
  juego de palabras con *sight* no se traslada.
- El texto habla de las ondas sonoras y de la vía auditiva como si la
  audición ya se hubiera leído. En este libro, el capítulo de la audición
  viene después. Se conservó ese orden de la exposición.
- El recuadro de los errores de refracción no lleva número en el encabezado,
  pero el apartado de la ceguera remite al «Box 8». La traducción lo titula
  **Recuadro 8**.
- El cuerpo cita «Weiskrantz, 1997»; la referencia del libro es Weiskrantz
  (1999). Se conservó el año de cada lugar.
- La referencia de Weiskrantz y Warrington (1974) intercala «K., Sanders, M.
  D., & Marshall, J.» antes del título. Se conservó esa forma.
- El texto llama a NICE «National Institute for Health Care and Excellence».
  Se tradujo esa formulación. El nombre oficial es National Institute for
  Health and Care Excellence.
- En las ideas principales, la miopía se presenta como ejemplo tanto de un
  aparato dióptrico demasiado débil como de uno demasiado potente. En el
  cuerpo del capítulo, la miopía corresponde al poder excesivo y la
  hipermetropía, al poder insuficiente. Se tradujo cada pasaje como está.
