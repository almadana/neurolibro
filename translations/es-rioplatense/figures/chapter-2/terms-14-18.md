# Terminología de las figuras 2.14, 2.15, 2.17 y 2.18

Localización al español rioplatense conforme a `GUIA_DE_TRADUCCION.md`.
Se preservan los números de las áreas de Brodmann, las líneas y las
atribuciones presentes en las fuentes.

## Figura 2.14

- parallel fibres → fibras paralelas
- molecular layer → capa molecular
- Purkinje cell layer → capa de células de Purkinje
- granule cell layer → capa granulosa
- white matter → sustancia blanca
- Purkinje cell → célula de Purkinje
- granule cells → células granulosas
- Purkinje cell axon → axón de célula de Purkinje
- mossy fibre → fibra musgosa
- climbing fibre from inferior olivary complex → fibra trepadora del complejo
  olivar inferior

## Decisiones fuera de la guía

- Se usa **complejo olivar inferior** para *inferior olivary complex*, forma
  anatómica precisa y habitual.
- Se usa **diencéfalo**, **corteza motora**, **corteza sensorial**,
  **somatosensorial**, **área de Broca**, **área de Wernicke**, **putamen**,
  **globo pálido** y **núcleo accumbens**, de acuerdo con la nomenclatura
  neuroanatómica de uso extendido.
- En la figura 2.17, *brain* se traduce como **encéfalo** porque designa el
  conjunto de regiones encefálicas y no exclusivamente el cerebro.
- Se adopta **olfacción** para el rótulo funcional breve *olfaction*.
- La fuente cuyo nombre contiene `fig2.16` corresponde, según la numeración de
  destino solicitada, a la figura 2.17.
- Las imágenes se amplían uniformemente a cuatro veces sus dimensiones
  originales mediante remuestreo Lanczos y se exportan como PNG a 300 ppp.
