# Terminología de las figuras 2.9–2.11

La columna «Origen» distingue las formas fijadas de manera explícita por
`GUIA_DE_TRADUCCION.md` de las decisiones adoptadas para estas figuras. Los
nombres propios y anatómicos internacionales se conservaron cuando corresponde.

## Figura 2.9

- sensory receptor → **receptor sensitivo** — decisión nueva, coherente con
  *sensory neuron*.
- muscle → **músculo** — decisión nueva.
- sensory neuron → **neurona sensitiva** — guía.
- motor neuron → **neurona motora** — guía.
- neuronal cell body in dorsal root ganglion → **cuerpo celular neuronal en el
  ganglio de la raíz dorsal** — «cuerpo celular», «neuronal» y «dorsal»:
  guía; «ganglio de la raíz dorsal»: decisión anatómica nueva.
- axons ascend dorsal column to medulla → **los axones ascienden por la columna
  dorsal hasta el bulbo raquídeo** — «axón» y «bulbo raquídeo»: guía;
  «columna dorsal»: decisión anatómica nueva.
- dorsal column → **columna dorsal** — decisión anatómica nueva.
- dorsal root entry zone → **zona de entrada de la raíz dorsal** — decisión
  anatómica nueva.
- dorsal horn → **asta dorsal** — decisión anatómica nueva solicitada para esta
  localización.
- lateral column → **columna lateral** — decisión anatómica nueva.
- ventral horn → **asta ventral** — decisión anatómica nueva solicitada para
  esta localización.
- ventral root exit zone → **zona de salida de la raíz ventral** — decisión
  anatómica nueva.
- ventral column → **columna ventral** — decisión anatómica nueva.

## Figura 2.10

- forebrain → **prosencéfalo** — guía.
- diencephalon → **diencéfalo** — decisión anatómica nueva.
- thalamus → **tálamo** — guía.
- hypothalamus → **hipotálamo** — guía.
- cerebral hemispheres → **hemisferios cerebrales** — «hemisferio»: guía;
  combinación anatómica de la figura: decisión nueva.
- brainstem → **tronco encefálico** — guía.
- midbrain → **mesencéfalo** — guía.
- pons → **puente** — guía.
- medulla → **bulbo raquídeo** — guía; se evita «médula» a secas.
- cerebellum → **cerebelo** — guía.
- spinal cord → **médula espinal** — guía.

- dorsal view → **vista dorsal** — «dorsal»: guía; combinación nueva.

- base of hypothalamus → **base del hipotálamo** — «hipotálamo»: guía.
- mammillary bodies → **cuerpos mamilares** — decisión anatómica nueva.
- cerebral peduncle → **pedúnculo cerebral** — decisión anatómica nueva.
- optic tract → **tracto óptico** — «tracto»: guía; nombre anatómico nuevo.
- oculomotor nerve → **nervio oculomotor** — decisión anatómica nueva.
- trochlear nerve → **nervio troclear** — decisión anatómica nueva.
- trigeminal nerve → **nervio trigémino** — decisión anatómica nueva.
- base of pons → **base del puente** — «puente»: guía.
- abducens nerve → **nervio abducens** — decisión anatómica nueva.
- facial nerve → **nervio facial** — decisión anatómica nueva.
- vestibulocochlear nerve → **nervio vestibulococlear** — decisión anatómica
  nueva.
- hypoglossal nerve → **nervio hipogloso** — decisión anatómica nueva.
- spinal accessory nerve → **nervio accesorio espinal** — decisión anatómica

- pyramid → **pirámide** — decisión anatómica nueva.

  claves laterales se abrevia «bulbo raquídeo» como «bulbo» por el espacio.
- sensory / motor → **sensitivo / motor** — guía.
