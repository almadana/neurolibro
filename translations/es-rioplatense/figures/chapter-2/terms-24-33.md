# Rótulos de las figuras 2.24, 2.25, 2.27 y 2.33

La columna «Fuente» distingue las equivalencias fijadas por
`GUIA_DE_TRADUCCION.md` de las decisiones adicionales de nomenclatura
neuroanatómica. Las letras A/B y las flechas se conservan.

## Figura 2.24

- Dendrites → **Dendritas**. Fuente: guía.
- Cell body → **Cuerpo celular**. Fuente: guía (*soma* / cuerpo celular).
- Axon hillock → **Cono axónico**. Fuente: decisión adicional (nomenclatura
  anatómica estándar; el texto del capítulo usa la misma forma).
- Axon → **Axón**. Fuente: guía.
- Presynaptic terminal → **Terminal presináptica**. Fuente: decisión adicional
  coherente con *synapse* → **sinapsis** de la guía.

## Figura 2.25

- Dendrites → **Dendritas**. Fuente: guía.
- Cell body → **Cuerpo celular**. Fuente: guía.
- Axon → **Axón**. Fuente: guía.

## Figura 2.27

- Dendrites → **Dendritas**. Fuente: guía.
- Dendritic spines → **Espinas dendríticas**. Fuente: decisión adicional
  (nomenclatura neuroanatómica estándar).

## Figura 2.33

- Smooth muscle cell → **Célula muscular lisa**. Fuente: decisión adicional.
- Pericyte → **Pericito**. Fuente: decisión adicional.
- Neuron → **Neurona**. Fuente: guía.
- Astrocyte end foot → **Pie terminal del astrocito**. Fuente: decisión
  adicional; el capítulo traduce *end feet* como **pies terminales**.
- Endothelial cell → **Célula endotelial**. Fuente: decisión adicional.
- Basal lamina → **Lámina basal**. Fuente: decisión adicional (Terminología
  Anatómica Internacional).
- Lumen → **Luz**. Fuente: decisión adicional; en vasos sanguíneos se prefiere
  «luz» a «lumen».

## Figuras que no se modificaron

- 2.26: solo números 1–4; las categorías están en el epígrafe.
- 2.28: microfotografías y una escala `50 µm`.
- 2.29, 2.30, 2.31, 2.32 y 2.34: ilustraciones o micrografías sin rótulos
  ingleses.
