# Rótulos de las figuras 3.21 a 3.33

Este registro complementa `GUIA_DE_TRADUCCION.md` y el texto ya traducido
de Transmisión neuronal. Los símbolos, las siglas y las unidades se
conservan: Na⁺, K⁺, Ca²⁺, Cl⁻, Mg²⁺, mV, ms, AMPA, NMDA, GABA, GABA-A, PPSE
y PPSI.

Se tradujeron las trece figuras del capítulo. El crédito de Eliza Wolfson
queda en inglés: es el nombre de la ilustradora.

## Equivalencias que ya estaban en el texto

- action potential → **potencial de acción**
- membrane depolarisation → **despolarización de la membrana**
- resting membrane potential → **potencial de reposo**
- threshold → **umbral**
- axon hillock → **cono axónico**
- axon → **axón**
- myelin → **mielina**
- node of Ranvier → **nodo de Ranvier**
- saltatory conduction → **conducción saltatoria**
- passive conductance → **conductancia pasiva**
- presynaptic / postsynaptic neuron → **neurona presináptica / postsináptica**
- synaptic cleft → **hendidura sináptica**
- synaptic vesicles → **vesículas sinápticas**
- glutamate → **glutamato**
- metabotropic receptor → **receptor metabotrópico**
- G-protein coupled receptor → **receptor acoplado a proteína G**
- temporal / spatial summation → **sumación temporal / espacial**
- EPSP → **PPSE**
- IPSP → **PPSI**
- voltage-gated → **dependiente de voltaje**
- ligand-gated → **activado por ligando**
- inactivation gate → **compuerta de inactivación**
- afterhyperpolarisation → **poshiperpolarización**
- absolute / relative refractory period → **período refractario absoluto / relativo**
- gap junction, hemichannel, connexin → **unión comunicante, hemicanal, conexina**
- outside / inside → **fuera / dentro** (en estos diagramas, por el poco espacio; en el texto, exterior / interior)

## Decisiones adicionales

- terminal bouton → **botón terminal**. El texto del capítulo dice «terminal axónica»; en la figura se conserva el término anatómico del botón.
- cell body, en la Fig. 3.21 → **soma**, como en el resto del capítulo.
- sodium/potassium pump → **bomba Na⁺/K⁺**
- unmyelinated / myelinated axon → **axón no mielinizado / axón mielinizado**
- inactivated sodium channels → **canales de Na⁺ inactivados**
- permeability to sodium / potassium → **permeabilidad al Na⁺ / al K⁺**
- relative permeability → **permeabilidad relativa**
- sub-threshold depolarisation → **despolarización subumbral**
- threshold to fire → **umbral de disparo**
- dendritic / somatic synapses → **sinapsis dendríticas / somáticas**
- proximal / distal synapses → **sinapsis proximales / distales**
- gated by inhibitory synapses → **quedar bajo la compuerta de sinapsis inhibitorias**, como en el texto del capítulo.
- boosted by expression of more voltage-gated channels → **potenciarse con más canales dependientes de voltaje**. Acá «boosted» no es el reforzamiento del aprendizaje ni la regeneración del potencial de acción.
- intercellular space → **espacio intercelular**
- hydrophilic channel → **canal hidrofílico**
- plasma membranes → **membranas plasmáticas**
- connexin monomer → **monómero de conexina**
- closed / open → **cerrado / abierto**
- G-protein effector → **efector de la proteína G**
- indirect cellular signalling → **señalización celular indirecta**
