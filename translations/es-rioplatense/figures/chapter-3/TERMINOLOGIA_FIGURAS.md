# Rótulos de las figuras del capítulo de electrofisiología

Este registro complementa `GUIA_DE_TRADUCCION.md`. La columna de cada
equivalencia distingue las formas ya fijadas por la guía, o por el texto de
este capítulo, de las decisiones adicionales.

Los símbolos químicos, las unidades y las fórmulas se conservan: Na+, K+, Cl−,
Ca2+, ATP, ADP, Pi, mV, mEq/l, Å, E_K y los números.

## Equivalencias

- Electrical circuit → **circuito eléctrico**. Fuente: decisión adicional; el
  capítulo ya usa «circuito».
- Electrical circuits vs water pipes → **circuitos y caños**. Fuente: el
  capítulo traduce *pipe* como **caño**.
- Positive pole / negative pole → **polo + / polo −**. Fuente: el capítulo
  habla del polo positivo y del polo negativo.
- Battery → **pila**. Fuente: el capítulo.
- Electric current / current → **corriente**. Fuente: el capítulo.
- Height of water is like battery voltage → **altura = voltaje**. Fuente:
  decisión adicional, abreviada para caber en el esquema; *voltage* →
  **voltaje** ya está en el capítulo.
- Diameter of pipe like resistance → **diámetro = resistencia**. Fuente:
  decisión adicional; *resistance* → **resistencia** en el capítulo.
- Pipe is like wire → **caño = cable**. Fuente: el capítulo (*pipe* → **caño**,
  *wire* → **cable**).
- Constriction of pipe like resistor → **estrecho = resistencia**. Fuente:
  decisión adicional. El símbolo del circuito se rotula **resistencia**, como
  en el texto.
- Tap is like switch → **canilla = llave**. Fuente: el capítulo usa **canilla**
  e **interruptor**. En el esquema, donde no entra «interruptor», se usa
  **llave**, forma rioplatense equivalente.
- Volume of water flowing through like current → **caudal = corriente**.
  Fuente: decisión adicional; «caudal» es el volumen de agua que pasa por
  unidad de tiempo.
- Lightbulb → **lámpara**. Fuente: decisión adicional.
- Wire / axon → **cable / axón**. Fuente: el capítulo y la guía (*axon* →
  **axón**). La marca «e−» de la animación no se traduce.
- Signal generator with command voltage → **generador de señales con voltaje
  de comando**. Fuente: el capítulo.
- Membrane potential amplifier → **amplificador del potencial de membrana**.
  Fuente: la guía (*membrane potential* → **potencial de membrana**).
- Intracellular recording electrode → **electrodo de registro intracelular**.
  Fuente: decisión adicional, coherente con *intracellular* → **intracelular**.
- Squid giant axon → **axón gigante de calamar**. Fuente: el capítulo.
- Extracellular reference electrode → **electrodo de referencia extracelular**.
  Fuente: decisión adicional.
- Current-passing electrode → **electrodo de paso de corriente**. Fuente: el
  capítulo.
- Feedback amplifier → **amplificador de retroalimentación**. Fuente: el
  capítulo.
- Ampere meter → **amperímetro**. Fuente: decisión adicional.
- Extracellular / intracellular → **extracelular / intracelular**. Fuente: el
  capítulo (líquido extracelular e intracelular).
- Concentration (mEq/l) → **concentración (mEq/l)**. Fuente: decisión
  adicional; la unidad no se traduce.
- Cations / anions → **cationes / aniones**. Fuente: decisión adicional.
- Bicarbonate → **bicarbonato**. Fuente: decisión adicional.
- Sulphate → **sulfato**. Fuente: decisión adicional.
- Protein → **proteína**. Fuente: decisión adicional.
- Phosphate → **fosfato**. Fuente: el capítulo (fosfato, Pi).
- Outside cell / inside cell → **exterior / interior**. Fuente: el capítulo
  glosa *out* como exterior e *in* como interior.
- Low / high → **bajo / alto**. Fuente: decisión adicional. [K+] se conserva.
- Potassium leak channel → **canal de fuga de potasio** (en la figura pequeña,
  **canal de fuga de K+**). Fuente: el capítulo (*leak channel* → **canal de
  fuga**).
- Potassium channel / sodium channel / chloride channel → **canal de potasio /
  canal de sodio / canal de cloruro**. Fuente: la guía (*ion channel* → **canal
  iónico**) y el capítulo.
- K+ ion, Na+ ion, Cl− ion → **ion K+, ion Na+, ion Cl−**. Fuente: decisión
  adicional de orden; «ion» no cambia.
- Universal gas constant → **constante universal de los gases**. Fuente:
  decisión adicional.
- Temperature → **temperatura**. Fuente: decisión adicional.
- Equilibrium potential → **potencial de equilibrio**. Fuente: el capítulo.
- Concentration gradient → **gradiente de concentración**. Fuente: la guía.
- Valence (charge on ion) → **valencia (carga del ion)**. Fuente: decisión
  adicional.
- Faraday's constant → **constante de Faraday**. Fuente: decisión adicional.
  El nombre propio se conserva.
- Membrane potential → **potencial de membrana**. Fuente: la guía.
- Membrane permeability to different ions → **permeabilidad de la membrana a
  distintos iones**. Fuente: decisión adicional.
- Concentration gradients → **gradientes de concentración**. Fuente: la guía.
