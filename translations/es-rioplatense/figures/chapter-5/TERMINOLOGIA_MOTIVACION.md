# Terminología de la conducta motivada

Decisiones de este capítulo, alineadas con la guía y con los capítulos ya
publicados. Los rótulos de las figuras 5.21 a 5.26 están en español. En la 5.26 se dejó *PUTAMEN*, igual en español.

## Términos

- *motivated behaviour* → **conducta motivada**
- *feeding* → **alimentación**; *eating* → **comer** o **ingesta**, según la frase
- *homeostasis* → **homeostasis**
- *negative feedback* → **retroalimentación negativa**
- *set point* → **punto de ajuste**
- *drive* → **impulso**; *drive reduction* → **reducción del impulso**
- *arousal*, en la teoría de Hull → **activación**
- *reinforcer* / *reinforcement* → **reforzador** / **reforzamiento**
- *reward* → **recompensa**
- *operant conditioning* → **condicionamiento operante**
- *Skinner box* → **caja de Skinner**
- *basal metabolic rate* → **tasa metabólica basal (TMB)**; se menciona *BMR*
- *lateral / ventromedial hypothalamus* → **hipotálamo lateral / ventromedial**
- *ghrelin, orexin, leptin* → **grelina, orexina, leptina**
- *cholecystokinin* → **colecistoquinina (CCK)**
- *cue-potentiated feeding* → **alimentación potenciada por claves**
- *incentive motivation* → **motivación de incentivo**
- *incentive salience* → **saliencia incentiva**
- *liking* / *wanting* → **«agrado»** / **«deseo»**; en la primera distinción se conserva el inglés
- *nucleus accumbens* → **núcleo accumbens**
- *ventral tegmental area* → **área tegmental ventral**
- *entrainment* → **arrastre**
- *wild type* → **tipo silvestre**
- *dorsal striatum* → **estriado dorsal**; *putamen* queda igual
- *substantia nigra* → **sustancia negra**
- *pituitary* → **hipófisis**
- *mesolimbic / mesocortical / nigrostriatal / tuberoinfundibular pathway* → **vía mesolímbica / mesocortical / nigroestriatal / tuberoinfundibular**
- *mammillary body* → **cuerpo mamilar**; *optic chiasm* → **quiasma óptico**; *corpus callosum* → **cuerpo calloso**
