# Esquizofrenia: decisiones de esta pasada de texto

Las figuras 6.8 y 6.9 están en español (`es-fig-6-8.png`, `es-fig-6-9.png`). El crédito de Andrew Young queda en el atributo title. En la 6.8, el círculo inferior dice «Crianza» (el original dice Upbringing; el pie habla de factores sociales). «Factores precipitantes» no se corrigió a «precipitating». En la 6.9, verde es función normal y rojo es función anómala; los recuadros dicen corteza frontal, corteza temporal, salida normal, salida anómala y conducta.

## Términos

- schizophrenia → esquizofrenia. Persona con esquizofrenia; personas que viven con esquizofrenia. No se define a la persona por el diagnóstico.
- positive / negative / cognitive symptoms → síntomas positivos, negativos y cognitivos. psychosis → psicosis.
- hallucinations → alucinaciones. delusions → delirios (persecutorios, de grandeza, somáticos, de control, de referencia). thought insertion / removal / broadcasting → inserción, robo y difusión del pensamiento.
- salience attribution → atribución de saliencia.
- formal thought disorder → trastorno formal del pensamiento. neologisms → neologismos. word salad → «ensalada de palabras».
- El original distingue desire (avolition) y motivation (abulia). Se mantiene: deseo (avolición) y motivación (abulia). En la psiquiatría en español los dos términos se solapan.
- emotional blunting → embotamiento emocional. apathy → apatía. anhedonia, alogia, asocialidad, mutismo, catatonia, negativismo, estupor. posturing → adopción de posturas. catatonic restlessness → inquietud catatónica. affective flattening → aplanamiento afectivo.
- *dementia praecox* se conserva en latín y se glosa como demencia precoz. *dementia paranoides* queda en latín. hebephrenia → hebefrenia. *schizo* / *phren* quedan en griego en cursiva. dual personality → doble personalidad.
- precipitatory factors → factores precipitantes (igual que en trastornos del estado de ánimo; no se «corrige» a precipitating).
- concordance → concordancia. fraternal / dizygotic → gemelos dicigóticos (mellizos). identical / monozygotic → gemelos monocigóticos.
- basal ganglia → núcleos basales; en el primer uso se agrega «ganglios basales». dorsal striatum (caudate and putamen) → estriado dorsal (núcleo caudado y putamen). nucleus accumbens (ventral striatum) → núcleo accumbens (estriado ventral). ventral tegmental area → área tegmental ventral. midbrain → mesencéfalo. limbic forebrain → prosencéfalo límbico. mesolimbic → mesolímbico.
- grey matter → sustancia gris. cortical thinning → adelgazamiento cortical. working memory → memoria de trabajo. executive function → función ejecutiva. entorhinal cortex → corteza entorrinal.
- illicit drugs → drogas. Fármaco se reserva para la farmacología. cocaine → cocaína. amphetamine → anfetamina. phencyclidine → fenciclidina. ketamine → ketamina. dizocilpine (MK-801) → dizocilpina (MK-801). L-DOPA se conserva. LSD se desarrolla como dietilamida del ácido lisérgico.
- typical / atypical / third-generation antipsychotics → antipsicóticos típicos (primera generación) / atípicos (segunda generación) / de tercera generación. neuroleptics / neurolepsis → neurolépticos / neurolepsis.
- chlorpromazine → clorpromazina. haloperidol y flupentixol se conservan. pimozide → pimozida. sulpiride → sulpirida. clozapine → clozapina. olanzapine → olanzapina. quetiapine → quetiapina. risperidone → risperidona. aripiprazole → aripiprazol. brexpiprazole → brexpiprazol. cariprazine → cariprazina. fluphenazine → flufenazina.
- 5HT-2 y 5HT2 del original → 5-HT2. GABA → ácido gamma-aminobutírico (GABA) en el primer uso.
- agranulocytosis → agranulocitosis. leucopoenia y leukopenia → leucopenia. akathisia → acatisia. tardive dyskinesia → discinesia tardía. resting tremor → temblor de reposo. partial agonists → agonistas parciales. trace amines → aminas traza.
- depot / LAIs → preparado de depósito / fármaco inyectable de acción prolongada (LAI).
- ECT → choque electroconvulsivo (TEC), como en el capítulo anterior. insulin shock → choque insulínico. pentylenetetrazol [*Metrazol*] → pentilentetrazol [*Metrazol*]. frontal lobotomy → lobotomía frontal. asylums → manicomios.
- CBT → terapia cognitivo-conductual (TCC). family therapy → terapia familiar.
- ICD → Clasificación Internacional de Enfermedades (CIE). Los criterios de la CIE-11 son una cita: se traducen y se marca «Traducción propia». La línea Source queda en inglés.
- Varones y mujeres para la variable de sexo del inicio. Las comillas de «poseídas» y «locas» se conservan.

## Erratas del original que no se corrigen en silencio

- El cuerpo cita «(Figure 10)»; el pie es Fig 6.8. La llamada quedó como Figura 6.8.
- «Schnieder» en la segunda mención de Kurt Schneider. Se tradujo el nombre correcto.
- «hereditable» → hereditario. «considerably lower that» → menores de lo que se esperaría. «uncertainly» → incertidumbre. «there use» → su uso. «slower in onset that» → más lentos en el inicio que. «is good predictor» → es un buen predictor. «showing decrease cortical volume» → que muestran una disminución del volumen cortical. «changes glutamate function» → cambios en la función del glutamato. «the individuals reactions» → las reacciones de la persona.
- «ventral tegmental are» → área tegmental ventral.
- «red indicated abnormal function» → el rojo indica función anómala.
- «the most consistent changes that have been observed is» → los cambios más consistentes que se observaron son.
- En el recuadro, «Diagnostic and Statistical Manual of the (DSM» está truncado. Se usó el nombre completo, que el capítulo ya da antes.
- «first rank» → de primer rango. Más adelante el original dice «first order symptoms» → de primer orden. No se unificaron.
- «neurogenerative processes»: se tradujo como procesos neurogenerativos. Es probable que el original quisiera decir neurodesarrollo o neurogénesis.
- «lusaridone» → lusaridona. El nombre establecido es lurasidona (lurasidone). No se sustituyó.
- El ítem f de la cita de la CIE-11 corta en «inappropriate emotional)». Se tradujo el sentido esperable («respuestas emocionales inapropiadas») y falta la puntuación entre las dos oraciones.
- leucopoenia y, más adelante, leukopenia: ambas quedaron como leucopenia.
- Hay un `<h3>` vacío antes de «Changes in brain structure» y un `<h2>` vacío antes de las referencias. No se copiaron.
- El título «Third and fourth generation antipsychotics» anuncia una cuarta generación que el párrafo no describe. El título se tradujo tal cual.
- La prevalencia del panorama es 0,3 a 0,7 % y la de las ideas clave es aproximadamente 0,5 %. No se reconciliaron.
- El recuadro de gemelos equipara la «tasa de concordancia entre los gemelos» con la tasa poblacional. Se tradujo como está: son medidas distintas.
- El círculo inferior de la Figura 6.8 dice «Upbringing»; el pie habla de factores sociales. El pie se tradujo como está.
